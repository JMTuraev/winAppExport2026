EKSPORT MONITOR — AppWin (Windows ilova), 1-bosqich
====================================================

Ishga tushirish
---------------
  D:\2026 export\AppWin\EksportMonitor.exe   — alohida oynali dastur (brauzer emas).
  Yorliq: exe ustida o'ng tugma → «Send to → Desktop (create shortcut)».
  Birinchi ochilishda Windows Firewall so'rasa — «Ruxsat» (xodimlar ulanishi uchun).
  Birinchi marta: superadmin login «admin», paroli D:\2026 export\data\ADMIN_PAROL.txt faylida
  (yoki EksportMonitor.exe --console bilan ochsangiz qora oynada). Kirgach parol o'zgartiriladi.

  Ishlamasa: AppWin\appwin.log faylini yuboring. EksportMonitor.exe --console — xatolarni oynada ko'rsatadi.
  Ishga_tushirish.bat — eski usul (server + brauzer), zaxira variant.

Talablar: Windows 10/11 (Microsoft Edge WebView2 va .NET Framework 4.7+ odatda o'rnatilgan bo'ladi).
AppWin MUSTAQIL: python\, app\ (sayt kodi), vendor\ — hammasi AppWin ichida. EksportMonitor papkasi kerak emas.
Bir marta: Mustaqil_qilish.bat — EksportMonitor'dan python/app/vendor ni AppWin ichiga ko'chiradi (eski tartibdan o'tish).
Ma'lumotlar: AppWin yonidagi data\ (D:\2026 export\data) — config.json da "data_dir" bilan o'zgartirish mumkin.

config.json (AppWin\)
---------------------
  "mode": "server"      — bu kompyuter server (siz). Ma'lumot + tarmoq shu yerda.
  "mode": "client"      — xodim kompyuteri: faqat oyna, "server_url": "http://192.168.1.10:8765"
                          (config.client.example.json — namuna). Xodim brauzerda ham ochishi mumkin.
  "backup_dir"          — tashqi disk papkasi, masalan "E:\\EksportMonitor_zaxira" (ikki \\ bilan).
  "host": "0.0.0.0"     — tarmoqqa ochiq; "127.0.0.1" — faqat shu kompyuter.

Zaxira (server rejimi)
----------------------
  Oyna yopilganda modal: «Zaxira nusxa olinsinmi?» — Ha: tashqi diskka yozib yopadi; Yo'q: shunchaki yopadi; Bekor.
  Tashqi diskda: <backup_dir>\YYYY-MM-DD_HH-MM\export.db + hujjatlar; 30 kunlik + har oy 1 tasi 12 oy saqlanadi.
  Disk ulanmagan bo'lsa holat qatorida qizil «Zaxira diski ulanmagan!».
  Superadmin → «Zaxira va server»: hozir zaxiralash, zaxirani tekshirish (jonli baza bilan solishtiradi).
  Ichki zaxira (data\backups) avvalgidek ishlaydi.

Nima bor
--------
  Oyna ichida — hozirgi sayt o'zgarishsiz. Oldin login oynasi.
  Login, rollar (Superadmin / Operator / Ko'ruvchi / Tuman xodimi), audit (kim · qachon · IP · nima qildi, Excel).
  Ko'ruvchi o'zgartira olmaydi — rad etiladi va jurnalga tushadi. Zaxiradan qaytarish / bazani tozalash / qayta init — faqat superadmin.
  5 marta noto'g'ri parol → 30 soniya kutish. Vaqtinchalik parol bilan kirgan xodim avval parolini o'zgartiradi.
  Superadmin panel: oynadagi «Dastur» menyusi → «Superadmin panel» (yoki brauzerda /admin).
  «Dastur» menyusi: Sayt · Chat · Superadmin panel · Tashqi diskka zaxira · Brauzerda ochish · Yangilash · Chiqish.

Chat (ichki, faqat ofis tarmog'i) — Telegram ko'rinishida
---------------------------------
  Har ekranning o'ng pastki burchagida doim chat tugmasi turadi (sayt, Superadmin panel) — ustidagi qizil raqam:
  o'qilmagan xabarlar soni. Bosilsa o'ng tomonda chat oynasi (720px): CHAPDA suhbatlar ro'yxati (avatar, oxirgi xabar,
  vaqt, o'qilmaganlar), O'NGDA suhbat. Ro'yxat ustida qidiruv (Enter — xabarlardan) va jildlar: Hammasi · Xodimlar ·
  Guruhlar · Korxona. Oynadan tashqarini bosish, Esc yoki tugmani qayta bosish — yopiladi; yopiq paytda xabarlar
  «o'qildi» bo'lmaydi. «⤢» — to'liq ekranda ochish (/chat). «Dastur» menyusi → «Chat» ham shu oynani ochadi.
  Suhbat turlari: kanallar (# umumiy, # kunlik-hisobot, # rahbar-topshiriqlari — hamma ko'radi; superadmin/operator ochadi),
  guruhlar (✎ → «Yangi guruh»: nom + tanlangan xodimlar — faqat a'zolar ko'radi; a'zo qo'shish/chiqarish, guruhdan chiqish),
  xodimlar bilan shaxsiy suhbat (Xodimlar jildida barcha xodimlar: onlayn / oxirgi marta), korxona suhbatlari (INN bo'yicha).
  Xabarlar pufakchada: o'zingizniki o'ngda (yashil), ✓ — yuborildi, ✓✓ — o'qildi. Sichqonchaning o'ng tugmasi (yoki «⋯»):
  Javob · Ishga bog'lash · Nusxalash · Belgilash (pin) · Tahrirlash · O'chirish; ikki marta bosish — javob; ↑ — oxirgi
  xabaringizni tahrirlash. Belgilangan xabar suhbat tepasida turadi.
  ISHGA BOG'LASH (🔗, ko'p tanlov): bitta xabar/fayl bir vaqtda bir nechta korxonaga, sohaga (tarmoq), tumanga, vazifaga
  (doska) va xat/topshiriqqa (Kiruvchi xat / Chiquvchi xat / Topshiriq / Hujjat + № va nomi) bog'lanadi. Xabardagi yorliq
  bosilsa: korxona kartasi, korxona suhbati, «shu bo'yicha barcha xabarlar», «shu bo'yicha fayllar».
  Fayl: skrepka, oynaga tashlash yoki Ctrl+V. Bog'lanmagan fayl sariq «qaysi ishga tegishli?» bilan turadi.
  «Fayllar» paneli (ⓘ): Korxona / Soha / Tuman / Vazifa / Xat / Bog'lanmagan filtri; qidiruv — fayl nomi yoki kesim nomi.
  Ctrl+K — barcha xabar, fayl va kesimlardan qidirish (masalan «Тўқимачилик», «Ғиждувон», INN, «xat №1247»).
  Saytdan chatga: /chat#inn=<INN>.
  Saqlanadi: data\chat.db (xabarlar) + data\chat_files\ (fayllar) — tashqi zaxiraga kiradi, internetga chiqmaydi.

Хатлар — bo'lim xatlari reyestri va «xotirasi» (2.5.0)
-----------------------------------------------------
  Menyu → «Хатлар»: barcha chiquvchi/kiruvchi xatlar, ilovalar, bayonnoma va hisobotlar — har biri karta: sarlavha,
  qisqa mazmun, raqam, sana, kimga, qaysi xatga javob (bo'lim kiruvchi raqami 16-5338 va yuboruvchi raqami), asosiy
  raqamlar, bog'lanishlar: korxona (INN) · soha · tuman · davlat. Birinchi yuklama: Telegram «Экспорт чиқувчи хатлар»
  kanalining 2025–2026 fayllari (467 karta, Claude o'qib yozgan).
  QIDIRUV (yuqoridagi katta maydon, «/» tugmasi): kirill va lotin farqsiz, so'z shakllari («туркман» = «Turkmaniston»,
  «Туркманистонга»), korxona nomi yoki INN, xat raqami («16-5338»), xat matni ichidan ham. Natijada topilgan so'z sariq.
  Filtrlar: Тури · Кесим · Йил · Туман · Соҳа · Давлат; «⚠ Текширилмаган» — avtomatik o'qishda shubhali chiqqan kartalar;
  «Илова ва нусхалар» — ilovalarni alohida ko'rsatish; «Архив» — shovqin va takror nusxalar (standart yashirin).
  Karta ustidagi yorliqlar bosiladi: 🏭 korxona → korxona kartasi («Хатлар» tabi), soha/tuman/davlat → shu bo'yicha
  xatlar, ↩ raqam → shu raqamli barcha yozishmalar.
  Xat oynasi: Мазмуни · Файл (PDF shu yerda ochiladi) · Матн (fayl matni, ichidan qidirish) · Илова ва нусхалар ·
  Ёзишмалар (shu raqam tilga olingan boshqa xatlar). Tugmalar: ⬇ Юклаб олиш (Yuklamalar papkasiga), ✓ Тасдиқлаш,
  Архивга, ✎ Таҳрирлаш (sarlavha, mazmun, tur, raqam, sana, kimga, javob raqamlari, bog'lanishlar qo'shish/olib tashlash).
  + ХАТ ҚЎШИШ (Operator/Superadmin): faylni tashlang → dastur matnni o'qiydi (PDF matn qatlami, Word, Excel) va
  raqam, sana, javob raqami, korxona (INN yoki nom), tuman, davlat, sohani o'zi taklif qiladi (nuqtali chegarali
  yorliqlar — taxmin, keraksizini × bilan olib tashlang) → sarlavha yozing → Сақлаш. Skan PDF'da matn bo'lmaydi
  (serverda OCR yo'q) — maydonlarni qo'lda to'ldiring. Korxona kartasidan qo'shilsa korxona o'zi bog'lanadi.
  KORXONA KARTASI → «Хатлар (N)» tabi: shu korxonaga bog'langan xatlar (xatning o'zi yoki ilovasi) + yig'iq
  «Соҳаси ва тумани бўйича хатлар».
  Havola: /#xat/<id> — xat oynasini ochadi.
  Ko'ruvchi faqat o'qiydi. Har tahrir, tasdiq, qo'shish va yuklab olish auditga yoziladi.
  Saqlanadi: data\xatlar\xatlar.db (kartalar, matnlar, qidiruv indeksi) + data\xatlar\telegramdan\ (Telegram eksporti)
  + data\xatlar\qolda\YYYY\MM\ (qo'lda qo'shilganlar). Tashqi zaxira: xatlar.db har snapshotda; fayllar esa bitta
  umumiy <backup_dir>\_xatlar_fayllar\ papkasiga — faqat yangi/o'zgarganlari (birinchi marta ~2 GB, keyin tez).
  Import vositalari (Claude uchun): data\xatlar\_import\.

Yangilash (o'rnatishsiz)
------------------------
  Server (siz): Superadmin -> «Zaxira va server» -> «Yangilanish»: Tekshirish -> Yangilash (git pull) -> Qayta ishga tushirish.
  Repo: https://github.com/JMTuraev/winAppExport2026 (git-sozlash.bat bilan sozlangan). O'zgarishlar: git-push.bat / git-pull.bat.
  Sayt kodi (app\) endi AppWin ichida — bitta repo, bitta yangilanish. EksportMonitor (export2026) — eski, alohida.
  Qo'lda: fayllarni almashtiring -> «Qayta ishga tushirish» (yoki exe'ni yopib-oching).
  Xodim kompyuterlari (client rejimi): dastur har ochilganda o'zgargan fayllarni serverdan LAN orqali o'zi oladi
  va qayta ochiladi. Internet kerak emas. O'chirish: config.json -> "auto_update": false.

O'rnatuvchi (Setup.exe)
-----------------------
  dist\EksportMonitor-Admin-Setup.exe — server (admin) kompyuteri: C:\EksportMonitor ga o'rnatadi, ma'lumotlar papkasini
      so'raydi (mavjud bazangiz bo'lsa D:\2026 export\data ni ko'rsating), tashqi disk papkasi (ixtiyoriy), Firewall ruxsati,
      ish stoli yorlig'i. Birinchi kirish: admin / data\ADMIN_PAROL.txt.
  dist\EksportMonitor-Setup.exe — xodim kompyuteri: server manzilini so'raydi (http://<server IP>:8765), client rejimi,
      yangilanishlarni serverdan o'zi oladi.
  Qayta o'rnatish (yangilash) = shu Setup.exe ni yana ishga tushirish: config.json va data\ saqlanib qoladi.
  O'chirish: Sozlamalar -> Dasturlar -> Eksport Monitor (data va config o'chmaydi).
  Yig'ish (dasturchi): build\installer.nsi — NSIS 3: makensis -DVERSION=2.0.0 installer.nsi (+ -DCLIENT xodim uchun).

Excel yuklash (Yuklamalar)
--------------------------
  Oynada «Excel» bosilsa «Saqlash» oynasi chiqmaydi — fayl to'g'ridan-to'g'ri D:\2026 export\Yuklamalar\ papkasiga tushadi
  (AppWin yonidagi Yuklamalar). Yuklash tugagach o'ng pastda xabar: fayl nomi + «Papkani ochish» / «Faylni ochish».
  Bir xil nom bo'lsa: fayl (2).xlsx, fayl (3).xlsx. Papkani o'zgartirish: config.json → "download_dir": "D:/boshqa/papka".
  Menyu: Dastur → «Yuklamalar papkasi (Excel)». Yozib bo'lmasa (xodim PC, Program Files) → Downloads\Eksport Monitor.

Xodimlar
--------
  Superadmin → Foydalanuvchilar → «+ Foydalanuvchi qo'shish». Xodim: brauzerda http://<server IP>:8765/
  yoki AppWin nusxasi (mode=client). IP holat qatorida va Superadmin → Server'da.

Fayllar
-------
  EksportMonitor.exe  — ishga tushirgich (python\pythonw.exe -m appwin.desktop), build\ ichida manbasi (launcher.c, app.ico)
  app\                — sayt (server, sahifalar, Excel) — endi AppWin ning bir qismi, shu yerda rivojlantiriladi
  python\             — o'rnatilgan Python 3.12 (embedded)
  appwin\desktop.py   — oyna (pywebview/WebView2), yopishdagi modal, server/client rejimi
  appwin\server.py    — server (EksportMonitor ustida): login, rollar, audit, LAN, shell, zaxira API
  appwin\auth.py      — users / user_sessions / user_audit — alohida data\appwin.db (zaxiradan qaytarish/tozalash ularga tegmaydi)
  appwin\backup.py    — tashqi disk zaxirasi
  appwin\xatlar.py    — Хатлар: reyestr, qidiruv (FTS5), karta tahriri, qo'lda qo'shish (matn o'qish + avtomatik nomzodlar)
  app\static\xatlar.js/.css — «Хатлар» sahifasi, xat oynasi, korxona kartasidagi «Хатлар» tabi
  appwin\update.py    — yangilanish: manifest/fayl (xodimlarga), git pull + restart (server)
  appwin\static\      — login.html, admin.html (Superadmin panel), brand.css/js + logo.svg (saytga logo va foydalanuvchi chipi — sayt fayllari o'zgarmaydi)
  vendor\             — pywebview, pythonnet, openpyxl, xlrd, pypdf (PDF matni) va boshqalar (Windows, Python 3.12)
